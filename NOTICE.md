The code in this repository is MIT licensed (see `LICENSE`).

The files under `vitaldb_resolution/data/` (fitted model parameters, the variable registry and the
exclusion rules) and `validation_report.json` / `tools/precision_results.json` were derived from the
VitalDB open dataset. VitalDB is distributed under the Creative Commons Attribution 4.0 International
licence (https://creativecommons.org/licenses/by/4.0/) and its own Data Use Agreement
(https://vitaldb.net/dataset/). These files contain fitted parameters, value lists and aggregate counts;
they contain no patient records and no case IDs. If you use them, credit VitalDB:

> Lee HC, Park Y, Yoon SB, Yang SM, Park D, Jung CW. VitalDB, a high-fidelity multi-parameter vital signs
> database in surgical patients. Sci Data. 2022;9:279. https://doi.org/10.1038/s41597-022-01411-5

The VitalDB data themselves are not included. Download them from https://vitaldb.net to rebuild the
registry, run the validation or build the Monte Carlo cache.
